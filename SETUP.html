Put the agent's code in the repository

.github/workflows/post.yml
Workflow text (shown below)
name: Braai social posts

on:
  schedule:
    # Every day at 17:17 South African time (15:17 UTC). The agent itself
    # decides whether today is a posting day (every 2nd day, see config.yaml).
    - cron: "17 15 * * *"
  workflow_dispatch:
    inputs:
      date:
        description: "Post for this date (YYYY-MM-DD). Empty = today"
        required: false
      force:
        description: "Post even if it's not a posting day"
        type: boolean
        default: false
      dry_run:
        description: "Create the post but don't publish it"
        type: boolean
        default: false

permissions:
  contents: write

concurrency: braai-posts

jobs:
  post:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install tools
        run: |
          sudo apt-get update -qq && sudo apt-get install -y -qq ffmpeg fonts-dejavu-core
          pip install -q -r requirements.txt
          curl -sSfL -o fonts/Anton-Regular.ttf https://github.com/google/fonts/raw/main/ofl/anton/Anton-Regular.ttf || true

      - name: Create today's post
        id: gen
        env:
          PEXELS_API_KEY: ${{ secrets.PEXELS_API_KEY }}
          PIXABAY_API_KEY: ${{ secrets.PIXABAY_API_KEY }}
        run: |
          ARGS=""
          [ -n "${{ inputs.date }}" ] && ARGS="$ARGS --date ${{ inputs.date }}"
          [ "${{ inputs.force }}" = "true" ] && ARGS="$ARGS --force"
          python -m braai_agent generate $ARGS

      - name: Save images to the repo (Instagram needs a public link)
        if: steps.gen.outputs.should_post == 'true'
        run: |
          git config user.name "braai-bot"
          git config user.email "braai-bot@users.noreply.github.com"
          git add posts
          git commit -m "Post for ${{ steps.gen.outputs.post_dir }}" && git push

      - name: Keep a copy of the reel for 30 days
        if: steps.gen.outputs.should_post == 'true'
        uses: actions/upload-artifact@v4
        with:
          name: post-${{ github.run_id }}
          path: ${{ steps.gen.outputs.post_dir }}
          retention-days: 30

      - name: Publish to Instagram & Facebook
        if: steps.gen.outputs.should_post == 'true'
        env:
          META_ACCESS_TOKEN: ${{ secrets.META_ACCESS_TOKEN }}
          FB_PAGE_ID: ${{ secrets.FB_PAGE_ID }}
          IG_USER_ID: ${{ secrets.IG_USER_ID }}
        run: |
          sleep 20  # give GitHub a moment to serve the new images
          if [ "${{ inputs.dry_run }}" = "true" ] || [ -z "$META_ACCESS_TOKEN" ]; then
            echo "Dry run (no META_ACCESS_TOKEN secret yet, or dry_run chosen)"
            python -m braai_agent publish "${{ steps.gen.outputs.post_dir }}" --dry-run
          else
            python -m braai_agent publish "${{ steps.gen.outputs.post_dir }}"
            git add posts && git commit -m "Published ${{ steps.gen.outputs.post_dir }}" && git push || true
          fi

3

Get a free Pixabay photo key

3 min
  1. Sign up (free) or log in at Pixabay.
  2. Open the API docs page while logged in. Scroll to Search Images → Parameters: the key row shows your API key in green.
  3. Copy the key and keep it for step 8.

Pexels has paused new keys, so Pixabay replaces it. No key at all still works: the agent then uses Openverse.

Sign up on Pixabay ↗Open API docs (your key) ↗
4

Make sure Instagram is a business account linked to your Page

3 min
  1. In the Instagram app: Settings → Account type and tools. It should say Business or Creator. If not, tap Switch to professional account.
  2. In Meta Business settings, open Accounts → Instagram accounts. @best_braai should be listed and connected to the Best Braai Page. If not, click Add and log in to Instagram.
Open Instagram accounts ↗
5

Create a Meta app

5 min
  1. Click Create app. Name it Best Braai Poster and use your email.
  2. For use cases, pick Manage everything on your Page and Manage messaging & content on Instagram. If those aren't offered, choose Other → Business.
  3. When asked for a business portfolio, choose Best Braai, then click Create app.
Create Meta app ↗
6

Create a posting key that never expires

7 min
  1. Open System users and click Add. Name: braai-bot, role: Admin.
  2. Click Assign assets. Give it full control of the Best Braai Page, the Instagram account and the Best Braai Poster app.
  3. Click Generate new token, choose the app, set expiry to Never, and tick the permissions below.
  4. Copy the token and keep it for step 8. Don't paste it in a chat or email. Anyone with it can post on your page.
Open System users ↗
pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management

9

Test run (nothing gets posted)

5 min
  1. Open the workflow page. If GitHub asks, click I understand my workflows, go ahead and enable them.
  2. Click Run workflow, tick force and dry_run, then click the green Run workflow.
  3. When it finishes (about 2 minutes), open the run and download the file under Artifacts to see the feed image, story and reel.
Open workflow ↗
10

Go live

2 min
  1. Click Run workflow again, tick only force, and run it. This time it really posts.
  2. Check @best_braai and your Facebook Page for the new post, story and reel.
  3. From now on it runs by itself every day at 17:17 and posts every second day. You don't need to do anything else.
